# Hello!

**Thank you for checking out my blog.**

I have only just begun getting the website back in order. In a way, this website resembles my room, in the sense that I let everything pile up but periodically spend loads of effort cleaning it up. 

It was quite a pleasant surprise that no one has taken up this domain name, so I bought it for myself two years ago, when I first took my baby steps into web development. Now I am two years older and still taking baby steps. Lovely.

I had (and still have!) **ambitious plans** for this website. My plans were to make this interactive website with an Emu Otori (from Project Sekai) 3D model and play around with it, and I will continue to work towards that.
